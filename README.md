### Sobre o trabalho

  **O programa realiza a criptografia de uma palavra (com até 15 caracteres minúsculos) utilizando a combinação de um deslocamento fixo (SHIFT) e um deslocamento dinâmico baseado numa sequência matemática.
Ao final da execução, o resultado é gravado automaticamente no ficheiro resultado_criptografia.txt.**

**Utilizamos a sequência de Fibonacci.**
